# pytools v1.0.0 — primeira release

Primeira versão estável do **pytools**, uma coleção de ferramentas Python
portáteis, independentes e reutilizáveis.

## Ferramenta disponível: Logger General 1.0.0

- Logger humano com níveis `DEBUG`, `INFO`, `WARNING`, `ERROR` e `CRITICAL`,
  com cores ANSI no terminal e logs persistidos **sem** escapes ANSI.
- Formatação Pretty Print de JSON/JSONL com destaque sintático e semântico,
  incluindo valores de status como `success`, `denied` e `failed`.
- Visualização incremental de arquivos JSONL sem alterar o conteúdo original.
- Saída HTML escapada para Jupyter, com cores CSS e exemplos de uso.
- Notebook Jupyter e versão Markdown com saídas textuais e prévias SVG coloridas.
- Módulo principal `logger/logger_general.py` portátil, **somente stdlib**,
  Python 3.10+ e sem dependências de runtime.
- Testes automatizados, exemplos offline, Makefile na raiz e em `logger/`.
- Preservação histórica do logger original **as-is** em `legacy/logger.py`
  (não é importado/executado pela implementação nova).

## Começar

Usando Python 3.10+ e GNU Make na raiz do repositório:

```powershell
make doctor
make test
make check
make logger-demo
make logger-pretty FILE=examples/events.jsonl COLOR=always
```

Para reutilizar o motor em outra aplicação, basta copiar
`logger/logger_general.py`. Dependências para Jupyter são opcionais.
